# Sahil Gogna - Portfolio Website

A minimalist personal portfolio website with light/dark mode toggle.

## Features

- 🌓 **Light/Dark Mode** - Toggle with localStorage persistence
- 📱 **Responsive Design** - Mobile-first layout
- 🎥 **Media Embeds** - YouTube videos and Instagram Reels
- ⚡ **Fast & Lightweight** - Pure HTML, CSS, and JavaScript

## Sections

- **Home** - Profile, social links, and CTA buttons
- **About** - Bio, YouTube videos, and Instagram Reels

## Tech Stack

- HTML5
- CSS3 (CSS Variables for theming)
- Vanilla JavaScript

## Run Locally

```bash
# Clone the repository
git clone https://github.com/SahilGogna/about-me.git

# Navigate to the directory
cd about-me

# Start a local server
python3 -m http.server 8080

# Open http://localhost:8080 in your browser
```
